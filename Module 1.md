## 1. Why Cloud Computing?

Traditional IT infrastructure requires organisations to purchase, install and maintain their own physical hardware, including servers, storage and networking equipment.

Cloud computing provides an alternative by allowing organisations to access computing resources through the internet without having to own and maintain all of the physical infrastructure themselves.

Cloud computing can help organisations:

- Reduce infrastructure costs
- Scale resources when demand changes
- Deploy applications more quickly
- Access resources from different locations
- Reduce the amount of physical infrastructure they need to manage

---

## 2. Definition of Cloud Computing

**Cloud computing** is the on-demand delivery of computing resources over the internet.

These resources can include:

- Computing power
- Storage
- Databases
- Networking
- Applications
- Security services
- Development tools

Instead of purchasing physical hardware, organisations can use resources provided by a cloud service provider.

### Key idea

> Cloud computing allows organisations to access computing resources when they need them rather than owning and maintaining all of the underlying infrastructure.

---

## 3. Who Uses Amazon Web Services (AWS)?

**Amazon Web Services (AWS)** is a cloud computing platform that provides a wide range of cloud services to organisations and individuals.

AWS is used by organisations of different sizes and across different industries.

Examples of workloads that can be hosted using AWS include:

- Websites and web applications
- Data storage
- Databases
- Software development
- Data analytics
- Machine learning
- Enterprise applications

AWS allows customers to access computing infrastructure without having to build and maintain their own physical data centres.

---

## 4. Brief History of Cloud Computing

Cloud computing developed from earlier approaches to sharing computing resources.

### Main development

- **Mainframe computing:** Multiple users could access computing resources from a central system.
- **Client-server computing:** Users accessed services provided by central servers.
- **Virtualisation:** Physical hardware could be divided into multiple virtual computing environments.
- **Cloud computing:** Computing resources became available on-demand over the internet.

Cloud computing allowed organisations to move away from relying entirely on physical infrastructure that they owned and managed themselves.

---

## 5. Client-Server Model

The **client-server model** is a computing model where a client requests a service or resource from a server.

### Client

The **client** is the device or application making the request.

Examples:

- Laptop
- Smartphone
- Web browser

### Server

The **server** provides the requested resource or service.

For example:

1. A user opens a web browser.
2. The browser sends a request to a web server.
3. The server processes the request.
4. The server sends the requested information back to the client.

### Key idea

> **Client = requests the service**  
> **Server = provides the service**

Cloud computing builds on this type of architecture by providing computing resources through network connections.

# 6. Six Benefits of Cloud Computing

Cloud computing provides several important benefits.

### 1. Pay-as-you-go

Customers can pay for the resources they use instead of making large upfront investments in physical infrastructure.

### 2. Scalability

Resources can be increased or decreased depending on the organisation's requirements.

For example, a website can add computing resources when traffic increases.

### 3. Elasticity

Resources can automatically adjust to changes in demand.

> High demand → More resources  
> Low demand → Fewer resources

### 4. Global Reach

Cloud providers operate infrastructure across different geographical locations, allowing organisations to provide services to users around the world.

### 5. Faster Deployment

Cloud resources can be provisioned much faster than purchasing and installing physical hardware.

### 6. Reduced Infrastructure Management

The cloud provider manages much of the underlying physical infrastructure, reducing the amount of hardware maintenance required by the customer.

---

# 7. Deploying to the Cloud

**Cloud deployment** involves moving or creating applications, data and computing resources within a cloud environment.

Instead of deploying an application entirely on physical servers owned by an organisation, the application can be deployed using cloud infrastructure.

A typical cloud deployment may involve:

1. Selecting the required cloud resources
2. Configuring the resources
3. Deploying applications or data
4. Managing and monitoring the environment
5. Scaling resources when necessary

Cloud deployment allows organisations to quickly create and modify their computing environments.

# 8. Cloud Computing Models

Cloud computing services can be divided into three main service models.

## Infrastructure as a Service (IaaS)

**IaaS** provides fundamental computing infrastructure through the cloud.

Examples include:

- Virtual machines
- Storage
- Networking

The cloud provider manages the physical infrastructure while the customer has greater control over the operating system, applications and configuration.

### Key idea

> **IaaS = Infrastructure**

---

## Platform as a Service (PaaS)

**PaaS** provides a platform that developers can use to build, deploy and manage applications.

The cloud provider manages more of the underlying infrastructure, allowing developers to focus more on their applications.

### Key idea

> **PaaS = Platform for developing applications**

---

## Software as a Service (SaaS)

**SaaS** provides complete software applications through the internet.

The cloud provider manages the underlying infrastructure and software.

### Key idea

> **SaaS = Complete software application**

---

## IaaS vs PaaS vs SaaS

| Model | What is provided? | Customer responsibility |
|---|---|---|
| **IaaS** | Infrastructure | Higher |
| **PaaS** | Application development platform | Shared |
| **SaaS** | Complete software | Lower |

### Easy way to remember

**IaaS → Infrastructure**  
**PaaS → Platform**  
**SaaS → Software**

As you move from **IaaS → PaaS → SaaS**, the cloud provider takes responsibility for more of the environment.

---

# 9. Cloud Computing Deployment Models

Cloud deployment models describe how cloud infrastructure is made available.

## Public Cloud

A **public cloud** is operated by a third-party cloud provider and provides cloud resources to multiple customers.

Examples include:

- AWS
- Microsoft Azure
- Google Cloud

Customers use the provider's infrastructure rather than owning the underlying physical hardware.

---

## Private Cloud

A **private cloud** is a cloud environment dedicated to a single organisation.

It can provide greater control over the environment but may require more management and resources.

---

## Hybrid Cloud

A **hybrid cloud** combines public and private cloud environments.

An organisation may use a private cloud for certain workloads while using public cloud services for others.

### Key idea

> **Hybrid Cloud = Public Cloud + Private Cloud**

## Module 2 Summary

Cloud computing provides organisations with on-demand access to computing resources over the internet. It developed from earlier computing models such as mainframe and client-server computing, with technologies such as virtualisation helping enable modern cloud environments.

AWS is a major cloud provider that allows organisations to access computing, storage, networking and other services without having to maintain all of the underlying physical infrastructure themselves.

The main cloud service models are **IaaS, PaaS and SaaS**, while the main deployment models are **public, private and hybrid cloud**.
